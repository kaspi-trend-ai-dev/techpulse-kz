# HARMEX MEDIA

Russian-language news portal for Kazakhstan and the world: https://harmex.asia/.

HARMEX MEDIA is the media direction of HARMEX; HARMEX Electronics is the commercial electronics direction. Commercial promotions are labeled and separated from news.

The site is built and audited using `npm run check` and deployed with GitHub Actions. Keep the domain, article paths, and canonical URLs unchanged in branding updates.

The GitHub repository retains the legacy name `techpulse-kz` to avoid disrupting existing automation. It is not the public brand.
